# Xarmoured brand system

Positioning: Offensive Security & Security Engineering. Identify how systems fail, demonstrate exploitable risk, help engineers fix the cause and verify the boundary afterward. Never imply unstaffed capabilities, a proprietary platform or invented enterprise scale.

Voice: precise, calm, evidence-focused, human. Prefer “Test the assumption. Trace the impact.” over “Industry-leading protection.” Describe scope and limitations. No fearmongering, fake statistics, customers, CVEs or testimonials.

Signature language: a fine boundary line interrupted by an orange attack path, closed by a cyan verification mark. Numbered stages and small evidence labels frame generous editorial typography. Diagrams are illustrative and explicitly labelled, never presented as live telemetry.

Colors: dark background #080B0F; elevated #0D1218; surfaces #121820/#18202A; text #F4F1EB; secondary #AAB3BD; muted #737F8C (nonessential decoration only); action #F47A45, hover #FF8B55; verification #55C8C3; success #72CFAE; warning #E4B567; actual risk #F06F73. Light background #F5F3EE; surface #FFFFFF; muted surface #ECE9E2; text #10151B; secondary #4F5964; orange #D95F2E (large accent; use darker #AC3D18 for small text); cyan #126B68 for readable light text. Use dark text on orange buttons. Light small-text semantic colors are deliberately darker: muted #58626D, verification #126B68, resolved #1C6C4C, warning #70500F, risk #A82431. These retain at least 4.5:1 against the light surfaces. Field borders use stronger neutral contrast than decorative rules.

Inter Variable: display/body. IBM Plex Mono: identifiers, process labels, dates and scope. Body 16px minimum in public reading flows, 1.65 line-height. Display fluid 44–88px; H2 32–58px; metadata 12px minimum. Avoid monospace paragraphs.

Space: 4/8/12/16/24/32/48/64/96/128px. Max reading width 72ch; wide container 1280px. Radius 3px for actions, 4–5px for technical panels; reserve rounded pills for state tags. Neutral 1px borders; no neon outlines. Shadows only for elevated navigation/dialogs.

Motion: 160–240ms controls, 400ms reveals; no infinite ambient animation. State changes must explain the path. Respect reduced motion. Lucide outline icons, 1.5–2px stroke. No hooded people, locks as filler, skulls, Matrix rain, stock consultancy photos, fake terminals or cursor effects. Prefer native SVG/CSS diagrams and actual research artifacts.

Dark is the brand flagship; light is a warm engineering journal with crisp rules and strong ink. Both modes preserve hierarchy and semantic color, never simple inversion. System preference is initial behavior; explicit preference persists.

Do: “Reproduce the finding. Verify the fix.” / Don’t: “Unparalleled cyber defense.” Do: show a real published advisory / Don’t: fabricate one to fill a layout.
