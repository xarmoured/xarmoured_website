# Design system

See brand-system.md for canonical tokens. Scope public composition under .public-site; preserve admin workflow layouts. Shared primitives: Brand, ButtonLink, Reveal, Status, ServiceIcon and Markdown. New structured experiences: lifecycle explorer, boundary diagram, report explorer, publication filters, grouped service navigation and theme control.

Navigation uses native disclosure buttons and a native modal dialog on mobile for focus containment, explicit first/last Tab wrapping, Escape and focus restoration. Menus work by click/keyboard, never hover alone. Forms retain server validation and associate errors with inputs. Use one H1, semantic sections, visible focus, skip link, 44px controls, no horizontal document overflow. Code blocks can scroll inside their own container.

No autoplay diagram progression; users select discovered/validated/remediated/verified states. Reveals use a short translation without fading text, keeping contrast stable throughout the effect. Reduced motion disables transforms and transitions. No charts or fake metrics on public pages. Existing Recharts remains admin-only and its activity chart is loaded on demand; unrelated admin editors do not download the chart library. Chart animation is disabled.

UI/UX Pro Max was already installed. Python 3 available. Initial cybersecurity query returned cyberpunk recommendations and was rejected. Narrower professional consulting/editorial search returned Accessible & Ethical guidance; applied keyboard, contrast, touch and whitespace principles. Palette and font recommendations were overridden by the explicit Xarmoured brief. No CLI installation or UI dependencies required.
